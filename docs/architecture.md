# Pulse — Architecture

Pulse is a hospitality marketing and growth platform designed for venues.

## Core Modules

### 1. Home (Command Centre)
- Daily overview of performance
- Tasks, opportunities, and content pipeline visibility
- Entry point for key actions

### 2. Reviews & Feedback
- Fetches reviews (Google via SerpAPI)
- Weekly automation (Monday 08:00 local time)
- AI-assisted responses
- “Needs Response” triage system

### 3. Content System
- Content Feed (idea ingestion)
- Content Pipeline (statuses)
- Library & Uploads (assets)

### 4. Pro Photo
- Enhances uploaded images
- Must preserve authenticity

### 5. Publishing
- Buffer integration
- Tracks scheduling and publishing status

## Tech Stack
- Frontend: Lovable
- Backend: Supabase
- AI: Gemini
